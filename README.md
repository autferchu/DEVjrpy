# DEVjrpy

Python learning project focused on fundamentals, logic, and practical exercises for junior developers.

## Overview

This repository was created to practice and demonstrate key Python concepts in a clear and professional way. It includes examples of variables, conditionals, loops, functions, lists, dictionaries, and a simple calculator application.

## Objectives

- Learn Python basics in a structured way
- Practice logic and arithmetic operations
- Understand conditional flow and iterative processes
- Implement reusable functions
- Build a simple user-interactive project
- Prepare a clean portfolio-style GitHub repository

## Included Files

- `hola_mundo.py` — Python learning examples and calculator project
- `main.py` — Basic FastAPI API example
- `.gitignore` — Ignores caches and local environment files

## Key Topics Covered

- Variables and data types
- `if`, `elif`, and `else`
- `for` and `while` loops
- Lists and dictionaries
- Logical and arithmetic operators
- Function creation and parameter passing
- Basic exception handling
- Interactive console menu

## How to Run

### Example script

```bash
python hola_mundo.py
```

### FastAPI application

```bash
python -m uvicorn main:app --reload
```

Then open the docs in the browser:

```text
http://127.0.0.1:8000/docs
```

## Technologies Used

- Python 3
- FastAPI
- Pydantic
- Uvicorn
