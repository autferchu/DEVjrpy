A Python learning project focused on fundamentals, logic, and practical exercises for junior developers.

## Overview

This repository was created to practice and demonstrate key Python concepts in a clear, organized, and professional way. It includes examples of variables, conditionals, loops, functions, lists, dictionaries, and a basic calculator application.

It also includes a small FastAPI API example to introduce API concepts and backend fundamentals.

## Project Goals

- Learn core Python syntax and concepts
- Practice logical thinking and problem solving
- Understand conditional structures and loops
- Apply reusable functions
- Build a basic interactive console project
- Present a clean, portfolio-style project on GitHub

## Included Files

- `hola_mundo.py` — Python fundamentals and calculator project
- `main.py` — Simple FastAPI API example
- `.gitignore` — Ignores cache and local environment files

## Topics Covered

- Variables and data types
- `if`, `elif`, and `else`
- `for` and `while` loops
- Lists and dictionaries
- Arithmetic and logical operations
- Functions with parameters
- Input validation and basic error handling
- Interactive menu-based console applications
- Basic API routing with FastAPI

## How to Run

### Python examples

```bash
python hola_mundo.py
```

### FastAPI app

```bash
python -m uvicorn main:app --reload
```

Then open:

```text
http://127.0.0.1:8000/docs
```

## Technologies

- Python 3
- FastAPI
- Pydantic
- Uvicorn
